# Décisions d'architecture (ADR)

Une note courte par décision. Numérotation continue sur 4 chiffres, jamais réutilisée.
Un ADR accepté ne se modifie pas : on en écrit un nouveau qui le remplace et on change le statut de l'ancien.

Modèle :

    # NNNN. Titre court à l'infinitif ou nominal

    - Statut : proposé | accepté | remplacé par NNNN | abandonné
    - Date : AAAA-MM-JJ
    - Affine : (optionnel) section de CLAUDE.md ou ADR précédent

    ## Contexte
    ## Décision
    ## Alternatives écartées
    ## Conséquences
