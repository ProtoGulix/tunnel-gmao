# Accueil acheteur

À la connexion, un compte acheteur arrive sur la page **Achats**, intitulée « Demandes
d'achat par statut ».

![Accueil acheteur](/captures/web-acheteur-accueil.webp)

## Ce que vous voyez

Les demandes d'achat sont rangées en quatre groupes, dans cet ordre.

- **En attente** : tout ce qui n'est pas encore commandé (à qualifier, sans fournisseur, à dispatcher, mutualisation, en chiffrage, devis reçu).
- **Commandé** : demandes commandées ou partiellement reçues.
- **Réceptionné** : demandes reçues.
- **Refusé** : demandes refusées.

Un groupe vide n'est pas affiché. Le nombre de demandes figure à côté du titre du groupe.

Chaque ligne indique le code de la demande (DA), l'article, la quantité, le statut, l'urgence
et l'intervention liée. La colonne « DI d'origine » ouvre la demande d'intervention d'où
vient l'achat, quand il y en a une.

## Et ensuite ?

Cette page est une vue de suivi. Pour agir sur les demandes, ouvrez l'écran **Demandes
d'achat** du menu : voir [Demandes d'achat](./demandes-achat).
