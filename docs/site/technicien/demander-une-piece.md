# Demander une pièce

Une pièce manque pendant une intervention : créez une **demande d'achat** depuis l'action
concernée. L'acheteur la traite ensuite.

![Détail d'une intervention sur le mobile](/captures/mobile-technicien-intervention.webp)

## Sur le mobile

1. Ouvrez l'intervention.
2. Dans la liste des actions, touchez le bouton d'ajout de demande d'achat de l'action
   concernée. Il n'apparaît que si votre rôle a le droit de créer une demande d'achat.
3. Le formulaire **Nouvelle demande d'achat** s'ouvre, avec la mention « Liée à une
   action ».

![Formulaire Nouvelle demande d'achat liée à une action](/captures/mobile-technicien-piece-formulaire.webp)

### Les champs

- **Article** (obligatoire). Recherchez un article du catalogue. S'il n'y est pas, touchez
  **Demande spéciale** et saisissez la désignation. Le badge « Demande spéciale » le
  rappelle.
- **Quantité** (obligatoire) : au moins 1.
- **Unité** : Pièce, Mètre, Kilogramme, Litre, Bidon, Boîte, Rouleau, Sachet ou Jeu. Elle
  se remplit seule si vous choisissez un article du catalogue.
- **Urgence** : Normal, Élevée ou Critique.
- **Raison** : panne, usure, réapprovisionnement…
- **Demandeur** : votre nom est proposé. Si vous videz le champ, la demande est faite au
  nom de « Système ».

Touchez **Créer**. L'écran confirme « Demande créée ! ».

Le compteur **DA** de l'intervention compte ces demandes.

## Sur le web

Le bouton **Demande d'achat** de l'accueil ouvre une demande spontanée. Elle sert à
réapprovisionner sans passer par une action.

## À savoir

La demande n'est pas une commande : l'acheteur la traite ensuite. Dans la recherche
d'article, chaque ligne affiche la référence, l'emplacement et le stock indiqué. Le
catalogue ne garde pas les mouvements de stock.
