# Mes tâches

![Accueil du mobile](/captures/mobile-technicien-accueil.webp)

## Sur le mobile

L'accueil affiche la section **Mes tâches**, avec leur nombre entre parenthèses. Elle liste
les tâches qui vous sont affectées et qui sont **à faire** ou **en cours**. Les tâches
terminées ou ignorées n'y figurent pas.

Chaque ligne montre le libellé de la tâche, son statut, le code de l'intervention et le nom
de l'équipement. Touchez une ligne : vous arrivez sur l'intervention qui porte la tâche.
Il n'existe pas d'écran dédié à une tâche.

S'il n'y en a aucune, l'écran affiche « Aucune tâche en cours ».

Sous la liste, **Accès rapide** propose : Préventif à faire, Interventions, Stock,
Équipements et QR Code.

## Le détail d'une intervention

![Détail d'une intervention sur le mobile](/captures/mobile-technicien-intervention.webp)

L'entrée **Intervention** de la barre du bas a trois onglets : **Planning**,
**Interventions** (la liste) et **Demandes**. Depuis la liste ou depuis une tâche de
l'accueil, vous ouvrez le détail d'une intervention. Il montre, de haut en bas :

- le code, le statut et l'équipement ;
- les compteurs **Actions**, **Heures** et **DA** (demandes d'achat) ;
- la description et la **demande liée** (ou « Aucune demande liée ») ;
- les **tâches**, avec une barre de progression. Les tâches de la gamme préventive passent
  en premier. Une tâche facultative est marquée « Optionnelle ». Si des étapes obligatoires
  restent à faire, l'écran le signale ;
- les **actions** déjà saisies.

Le bouton **Ajouter une action** reste en bas de l'écran (voir
[Saisir une action](/technicien/saisir-une-action)).

Une tâche se termine par une action liée, pas par un bouton : l'écran vous le rappelle.
Le bouton **Nouvelle tâche** permet d'en ajouter une, si votre rôle le permet.

## Sur le web

![Accueil web du technicien](/captures/web-technicien-accueil.webp)

L'accueil web du technicien est coupé en deux. À gauche, **Tâches à exécuter** ; à droite,
le planning de la semaine. En haut, les boutons **Demande d'inter** et **Demande d'achat**,
la navigation par semaine (bouton **Auj.** pour revenir à aujourd'hui) et le bouton **Fiche
semaine**, qui télécharge la fiche PDF.

Cet écran est l'accueil par défaut. Un administrateur peut attribuer une autre vue
d'accueil à un rôle.
