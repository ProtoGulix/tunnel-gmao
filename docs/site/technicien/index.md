# Technicien

Ce guide s'adresse aux techniciens de maintenance. Il décrit le travail au quotidien : voir
ses tâches, saisir ce qu'on a fait, signaler un problème, demander une pièce, clore une
intervention.

![Accueil du mobile, avec la liste Mes tâches](/captures/mobile-technicien-accueil.webp)

## Mobile d'abord

Le téléphone est l'outil du terrain. L'application mobile s'ouvre à l'adresse de votre
Tunnel suivie de `/m`. Le bureau (web) sert aux mêmes tâches, avec un écran plus grand.

Deux limites à connaître :

- **Pas de saisie hors ligne.** L'application a besoin du réseau pour enregistrer :
  attendez d'être connecté avant de saisir.
- **Le mot de passe se change sur le web**, pas sur le mobile (voir
  [Notifications et compte](/technicien/notifications)).

## Les pages

1. [Mes tâches](/technicien/mes-taches) : ce qui vous est confié, et comment ouvrir une
   intervention.
2. [Saisir une action](/technicien/saisir-une-action) : temps, type de travail,
   complexité, tâche liée.
3. [Signaler un problème](/technicien/signaler-un-probleme) : créer une demande
   d'intervention.
4. [Demander une pièce](/technicien/demander-une-piece) : créer une demande d'achat
   depuis une action.
5. [Clore ou rouvrir une intervention](/technicien/cloturer-rouvrir) : les motifs, les
   tâches annulées.
6. [Notifications et compte](/technicien/notifications).

## La barre du bas

Sur le mobile, cinq entrées restent accessibles en bas de l'écran : Accueil,
Intervention, Stock, Équipements et Préventif. Le QR Code se trouve dans l'accès rapide de
l'accueil.
