# Signaler un problème

Pour signaler une panne ou un besoin, créez une **demande d'intervention**. Un responsable
l'examine : accepter la demande crée l'intervention, ou la rejeter.

![Formulaire de demande d'intervention sur le mobile](/captures/mobile-technicien-demande.webp)

## Sur le mobile

Touchez **Intervention** dans la barre du bas, puis l'onglet **Demandes**. La liste se
filtre par statut ; le filtre « nouvelle » est choisi au départ, et chaque statut affiche
son nombre de demandes.

Touchez **Nouvelle demande**. Le formulaire **Nouvelle demande d'intervention** s'ouvre :

1. **Équipement** : recherchez-le par son code ou son nom.
2. **Votre nom** (obligatoire).
3. **Service** : facultatif, à choisir dans la liste.
4. **Description** (obligatoire) : décrivez le problème ou l'intervention souhaitée.

Touchez **Créer la DI**. Le formulaire ne s'envoie pas sans nom ni description.

## Suivre une demande

Touchez une demande dans la liste pour voir son détail : statut, description, demandeur,
service, dates, équipement et historique des changements de statut. Quand la demande a
donné lieu à une intervention, **Voir l'intervention** vous y emmène.

Le bouton **Créer l'intervention** n'apparaît que si votre rôle a le droit d'accepter une
demande. Il ouvre alors le formulaire de l'intervention à créer.

## Sur le web

Depuis l'accueil, le bouton **Demande d'inter** ouvre la saisie d'une demande
d'intervention.
