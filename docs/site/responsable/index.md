# Responsable

Ce guide s'adresse au responsable de la maintenance. Il décrit comment piloter le service
avec Tunnel : traiter les demandes, confier le travail, suivre le préventif, lire le bilan
et garder une trace fiable des décisions.

![Accueil direction technique : la file à traiter](/captures/web-direction-accueil.webp)

## Ce que votre rôle permet

Le responsable (rôle RESP) lit tout le métier et peut tout y écrire : demandes,
interventions, tâches, plans préventifs, équipements, achats. Trois points le distinguent
du technicien :

- il clôt une tâche sans action, avec un motif, et annule une étape obligatoire d'un plan
  préventif ;
- il exporte en masse les fiches d'interventions fermées ;
- il consulte le bilan du service et le journal d'audit.

Les comptes, les rôles et les règles d'audit restent à l'administrateur. Vous les
consultez, vous ne les modifiez pas.

## Où travailler

Votre travail se fait sur le **web**, au bureau. Le mobile sert au terrain : vous pouvez
l'utiliser, mais ces pages décrivent les écrans web.

## Les notions à connaître

Les définitions de base (demande, intervention, tâche, action, préventif, audit) sont dans
[Comprendre Tunnel](/comprendre/). Deux mots reviennent souvent ici :

- **Garant** : la personne affectée à une tâche. Elle répond de sa finalisation. Les
  **exécutants** sont les techniciens qui ont saisi des actions sur cette tâche. Garant et
  exécutant peuvent être différents : c'est un fonctionnement normal.
- **Décision hors travail normal** : clôture, réouverture, tâche annulée, rejet. Ces choix
  s'enregistrent avec un motif et leur auteur.

## Limites à connaître

- Le Bilan ne donne **aucun chiffre par technicien**, par choix.
- Un plan préventif « par compteur d'heures » n'a pas de relevé réel du compteur : son
  échéance s'affiche « non calculée ».
- Le catalogue de pièces ne gère pas de mouvements de stock : voir le guide de
  l'[acheteur](/acheteur/).
