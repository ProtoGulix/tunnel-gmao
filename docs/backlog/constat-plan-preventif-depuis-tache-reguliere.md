# Constat : plan préventif depuis « tâche régulière »

Accepter la demande d'un levier « tâche régulière » crée une intervention ponctuelle, pas de
plan préventif : la récurrence se perd. Idée : à l'acceptation, proposer de créer un plan
(fréquence du constat pré-remplie). Revue du 2026-11-26 (ADR 0045, point E).
