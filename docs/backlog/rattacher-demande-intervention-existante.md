# Rattacher une demande à une intervention existante

Constaté le 2026-11-27 (chantier ACD) : accepter une demande crée toujours une
intervention ; aucune route ne rattache une demande à une intervention déjà ouverte (cas
d'un doublon de panne). Touche le cycle de vie des demandes et l'audit : ADR à écrire avant.
