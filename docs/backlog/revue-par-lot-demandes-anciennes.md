# Revue par lot des demandes de plus de 90 jours

Proposée par la maquette de l'accueil direction (2026-11-28, ADR 0047) : un bouton « Revue
par lot » qui fait passer les demandes anciennes une à une (accepter, rejeter avec motif
d'audit, transformer en idée d'amélioration). En dev : 50 demandes de plus de 90 jours sur
58 (mesuré le 2026-11-27). Hors périmètre du chantier ADT.
